# تطبيق قدرات المغربي — iPhone

تطبيق SwiftUI أصلي للطالب وولي الأمر، مرتبط مباشرة بنفس حسابات وبيانات منصة
`qudratmaghrabi.com`. يدعم iOS 17 فأحدث ويستخدم Liquid Glass الأصلي على iOS 26
مع مظهر زجاجي متوافق للإصدارات الأقدم.

## ما تم تنفيذه

- تسجيل الدخول وإنشاء حساب طالب أو ولي أمر واستعادة كلمة المرور عبر Supabase Auth.
- لوحة طالب حقيقية: الكورسات المدفوعة، التقدم، النتائج والإشعارات.
- مكتبة دروس وتشغيل فيديو Bunny بتوقيع مؤقت من خادم المنصة.
- ملخص الدرس، المرفقات، خريطة الكورس، وتسجيل إتمام الدرس.
- اختبارات مؤقتة متعددة الخيارات وتصحيح آمن داخل Supabase دون كشف الإجابات للتطبيق.
- ملف شخصي قابل للتعديل، تسجيل خروج، وحذف الحساب نهائيًا من داخل التطبيق.
- لوحة ولي أمر لمتابعة الأبناء المرتبطين، تقدم الكورسات ونتائج الاختبارات.
- تحويل حسابات الإدارة إلى لوحة الويب بدل تكرار واجهة إدارة كاملة داخل الهاتف.
- واجهة عربية RTL، خطوط Frutiger، أيقونة App Store، وPrivacy Manifest.

## التشغيل في Xcode

1. ثبّت أحدث إصدار مستقر من Xcode.
2. افتح `QudratMaghrabi.xcodeproj`.
3. انتظر Xcode حتى ينتهي من تنزيل حزمة `supabase-swift`.
4. من Target **QudratMaghrabi > Signing & Capabilities** اختر Apple Developer Team.
5. تأكد أن Bundle Identifier هو `com.qudratmaghrabi.app` أو غيّره لمعرّف مسجل بحساب العميل.
6. اختر iPhone Simulator بنظام iOS 17 أو أحدث ثم Run.

الإعداد العام موجود في `Config.xcconfig`. يحتوي فقط على Supabase Publishable Key الآمن
للتطبيقات العامة؛ لا تضع فيه Service Role Key أو أي مفتاح سري.

## قبل الرفع إلى App Store Connect

- اختبر حساب طالب عليه اشتراك وكورس منشور، وحساب ولي أمر مرتبط بطالب.
- راجع بيانات الخصوصية في App Store Connect لتطابق `PrivacyInfo.xcprivacy`.
- جهّز Screenshots وSupport URL وPrivacy Policy URL.
- نفّذ Archive على جهاز Generic iOS Device ثم Validate App قبل الرفع.
- شراء المحتوى الرقمي داخل تطبيق iOS يجب أن يستخدم In-App Purchase؛ الإصدار الحالي يعرض
  الاشتراكات التي تمت على الموقع ولا يفتح Paymob داخل التطبيق.

## ملاحظات الأمان

- الفيديوهات لا تُخزّن كرابط عام؛ التطبيق يطلب رابط Bunny قصير العمر من API المنصة.
- الإجابات الصحيحة لا تصل إلى الطالب قبل التسليم؛ حساب الدرجة وحفظها يتمان في PostgreSQL.
- Row Level Security يفصل بيانات الطالب وولي الأمر، ولا يتيح لولي الأمر سوى الأبناء المرتبطين.
- حذف الحساب متاح داخل التطبيق امتثالًا لمتطلبات Apple.
