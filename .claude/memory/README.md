# ذاكرة مشروع «قدرات المغربي»

الملفات دي هي **الذاكرة الدائمة للمشروع**، متتبَّعة في Git عشان تتزامن بين كل الأجهزة والحسابات.

## القاعدة
- **أي جلسة جديدة:** اقرأ `MEMORY.md` أولًا، ومنه ادخل على الملف اللي يخص شغلك.
- **أي قرار أو معلومة دائمة** (قاعدة جديدة، معرّف، عطل وحلّه، مهمة مؤجَّلة): حدّث الملف المناسب هنا **واعمل commit** في نفس الجلسة.
- الملفات دي هي **المصدر الوحيد للحقيقة**. لو اتعارضت مع أي ملف تاني في المستودع، دي الصح.

## ممنوع
- **لا تُكتب هنا أي قيمة سرية** — مفاتيح، توكنات، كلمات مرور، محتوى ملفات `.p8` أو JSON حسابات الخدمة. الأسماء فقط.
- لا تُكتب هنا بيانات طلاب (بريد أو هاتف) إلا لو ضرورية لتوثيق حادثة، وبأقل قدر ممكن.

## ملفات قديمة في جذر المستودع
`PROJECT_HANDOFF.md` و`AGENTS.md` و`CLAUDE_HANDOFF.md` و`CLAUDE_START_PROMPT.md` — قديمة ومضلِّلة (لسه بتتكلم عن ميزة «ولي الأمر» الملغاة). **لا تعتمد عليها.** المرجع هو المجلد ده.
