## ✅ نُفِّذ (2026-09-02)
كل ملفات الذاكرة انتقلت إلى **`.claude/memory/` داخل مستودع المنصة (فرع `main`)** ومتتبَّعة في Git.
النتيجة: أي جهاز أو حساب أو مهمة جديدة → `git pull` → السياق كامل.

## النظام بثلاث طبقات
| الطبقة | المكان | المزامنة |
|---|---|---|
| الكود | GitHub (`main` للمنصة · `flutter-app` للتطبيق) | Git |
| السياق والقرارات والذاكرة | `.claude/memory/` في فرع `main` | Git |
| المحادثة | الجلسة | مؤقتة، لا تحتاج مزامنة |

## القاعدة الإلزامية
أي قرار أو معلومة دائمة جديدة ⇒ حدّث الملف المناسب في `.claude/memory/` **واعمل commit في نفس الجلسة**. الذاكرة اللي مش في Git = ذاكرة ضايعة على الجهاز التاني.
وأول أي جلسة: `git pull` قبل أي شغل، عشان ما تشتغلش على سياق قديم.

## الخلاصات اللي وصلنا لها قبل التنفيذ
- **رسالة `This task is linked to a different Claude desktop install` مالهاش مخرج.** كل مهمة مربوطة بجهاز واحد بالتصميم. الحل الوحيد «start a new task here».
- كريم عنده **حسابين Claude Pro**. تقسيم المشروع الواحد بينهم كان هيخلي كل جهاز بنص المخ — الحل ده (الذاكرة في Git) بيلغي المشكلة تمامًا لأن الذاكرة بقت في المستودع مش في الحساب.

## بنية المجلدات المعتمدة (الماك بوك اير)
```
Kareem-AI/
└── قدرات المغربي/
    ├── App/        (فرع flutter-app)
```

`PROJECT_HANDOFF.md` (قديم من 12 أغسطس، لسه بيتكلم عن ميزة «ولي الأمر» الملغاة) · `AGENTS.md` (سطر واحد) · `CLAUDE_HANDOFF.md` و`CLAUDE_START_PROMPT.md` (مش في Git).
**لا تعتمد على أي منها — المرجع هو `.claude/memory/`.**
